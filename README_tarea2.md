## Tarea 2 - Introducción a la Ciencia de Datos

## Descripción

En la presente entrega se genera el entrenamiento de distintos modelos de clasificación de texto, utilizando como base de datos las obras publicadas por Shakespeare.

## Archivos del Proyecto


- `script.py`: El script en Python en el cual obtenemos los resultados más relevantes.
- `informe.pdf`: Un informe detallado del proyecto, con respuestas a las preguntas de la tarea, resultados relevantes y gráficos.
